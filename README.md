
# LinkNotes 📝

A simple Chrome extension built using HTML, CSS and JavaScript.

## About the Project

LinkNotes helps users capture text from websites, save it as notes, organize notes using tags, and find related notes.

## Features

- Capture selected text from webpages
- Save notes
- Add topic tags
- Search saved notes
- Connect notes with common topics
- Delete notes

## Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Storage API
- Chrome Extension Manifest V3

## Project Structure

```text
LinkNotes/
├── manifest.json
├── popup.html
├── style.css
└── popup.js
```

## How to Install

1. Download or clone this repository.
2. Open Google Chrome.
3. Visit chrome://extensions/
4. Enable Developer Mode.
5. Click Load unpacked.
6. Select the LinkNotes project folder.
